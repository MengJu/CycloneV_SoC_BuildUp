Step-by-step series

手把手教你 Cyclone V SoC 設計流程

參考 RocketBoards 的參考設計，從 FPGA 硬體專案一路完成 Linux 系統與應用程式。

7 個實作單元
  1. 建立 FPGA 專案，並加入與 CPU 連結的 IP
  2. 建立 U-Boot
  3. 建立 Linux Kernel
  4. 建立並客製 Root File System
  5. 建立 Device Tree（DTB）
  6. 製作開機 SD Card
  7. 設置環境並撰寫 Linux C 應用程式
補充：原筆記提到新版 Quartus 已沒有 EDS，因此 Device Tree 的建立步驟可視實際工具版本與流程需求調整。
