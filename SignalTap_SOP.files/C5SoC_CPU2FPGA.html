製作可以開機的 SD CARD

怎樣讓 CPU 找到 FPGA 的燒錄檔

­          產生 Boot.txt 檔. 請建立一個 TXT 檔, 並將以下內容填入並存檔. 請將檔案放入 $LINUX_BIN/a9/ 資料夾

setenv fpgadata 0x2000000;

fatload mmc 0:1 ${fpgadata} sockit_ghrd.rbf;

printenv filesize;

fpga load 0 ${fpgadata} ${filesize};

bridge enable;

新手注意事項:

!  請確定你的 RBF 檔名

­          在 Ubuntu 如何新增一個 TXT 檔並把上面的內容輸入呢?

$cd $LINUX_BIN/a9

$sudo vim boot.txt

這樣就打開 boot.txt 了. 按 i 然後將上面紅字全部 copy and past 到 Ternimal 視窗.

按 esc 然後輸入 :wq 就存好檔了.

$sudo chmod +x boot.txt

新手注意事項:

!  沒有裝 vim?

$sudo apt install vim

 

­          將 Boot.txt 轉成 u-boot.scr 並放到 $LINUX_BIN/a9/

$cd $LINUX_BIN/a9

$mkimage -A arm -T script -O linux -d boot.txt u-boot.scr

新手注意事項:

!  不能 mkimage?

$sudo apt install uboot-mkimage

產生 IMG 檔

­          下載工具

$cd $TOP_FOLDER/

$sudo rm -rf sd_card && mkdir sd_card && cd sd_card

$wget https://releases.rocketboards.org/2021.04/gsrd/tools/make_sdimage_p3.py

$chmod +x make_sdimage_p3.py

新手注意事項:

!  這時候你找不到 $TOP_FOLDER? 太糟糕囉.

­          準備所需要的檔案,也就是之前建的. 如果沒有一些檔案, 那你就要查一下哪一個步驟沒做到.

$cd $TOP_FOLDER/sd_card

$mkdir sdfs && cd sdfs

$cp $LINUX_BIN/a9/zImage .

$cp $LINUX_BIN/a9/socfpga.dtb .

$cp $LINUX_BIN/a9/u-boot.scr .

$cp $TOP_FOLDER/arrow-sockit-ghrd/output_files/sockit_ghrd.rbf .

$mkdir extlinux

$echo "LABEL Linux Default" > extlinux/extlinux.conf

$echo "    KERNEL ../zImage" >> extlinux/extlinux.conf

$echo "    FDT ../socfpga.dtb" >> extlinux/extlinux.conf

$echo "    APPEND root=/dev/mmcblk0p2 rw rootwait earlyprintk console=ttyS0,115200n8" >> extlinux/extlinux.conf

新手注意事項:

!  Echo 指令就是把資料寫到檔案裡去.

!  Extlinux.conf 是指定 devices tree 的地方

­           準備 Root File System

$cd $TOP_FOLDER/sd_card

$sudo rm -rf rootfs

$mkdir rootfs && cd rootfs

$sudo tar xf $LINUX_BIN/a9/core-image-minimal-cyclone5.tar.gz

$sudo rm -rf lib/modules/*

$sudo cp -r $LINUX_BIN/a9/modules/* lib/modules

新手注意事項:

 

­          複製 U-Boot 的 Binary file

$cd $TOP_FOLDER/sd_card

$cp ../arrow-sockit-ghrd/software/bootloader/u-boot-socfpga/u-boot-with-spl.sfp .

新手注意事項:

­          製作 SD card IMG file.

$cd $TOP_FOLDER/sd_card

$sudo python3 ./make_sdimage_p3.py -f \

-P u-boot-with-spl.sfp,num=3,format=raw,size=10M,type=A2  \

-P sdfs/*,num=1,format=fat32,size=100M \

-P rootfs/*,num=2,format=ext3,size=300M \

-s 512M \

-n sdcard_cv.img

新手注意事項:

!  要注意 rootfs 的大小, 如果你有增加一些軟體的話.

!  -s 512 是 total 大小, 如果前面的大小有改, 會超過 512M, 那就要放大.

!  Sdcard_cv.img 可以自行改名字

­          在 $TOP_FOLDER/sd_card 這一個資料夾裡面應該要有一個 sdcard_cv.img 的檔案了.....找不到的….不是我的說明有問題, 就是你做錯了…>__<…

製作 Boot SD Card

­          利用 dd 指令燒錄 SD Card

•         要先找出 SD card 的位置.

•         不要插入 SD card 到到電腦. 並以下指令找出所有的記憶體名稱.

$cat /proc/partitions

新手注意事項:

•         插入 SD card 在找出所有的記憶體名稱. (比對沒有插入 SD card)

$cat /proc/partitions

新手注意事項:

•         你可能找出來的 SD card 名稱為 mmcblk0, 如果你的 sd card 不是空白的. 請用 "Disks" 這一個 App 將 SD card所有的 partition 清除.

•         再用下面指令將 IMG 檔燒錄到 SD Card.

$cd $TOP_FOLDER/sd_card

$sudo dd if=sdcard_cv.img of=/dev/sdd bs=1M

新手注意事項:

!  需要等一下下, Ubuntu 沒跟你說進度,不要以為當機!

開機

­          設置 EVB 開機設定.

•         J15 Jumper 接 Pin 2 and 3

•         J16 Jumper 接 Pin 2 and 3

•         J17 Jumper 接 Pin 1 and 2

•         J18 Jumper 接 Pin 1 and 2

•         J19 Jumper 接 Pin 2 and 3

•         SW6: on, off, on, off, on, on

  • 將 SD Card 插入 EVB, 就要準備開機囉.
  • 開機前, 要先確定你的 USB UART 能不能用, 也就是 Putty 能不能找到 USB UART.
  • 先打開 Terminal.

 

$sudo adduser username dialout

$sudo dmesg | grep tty

$lsusb

$sudo apt install putty

新手注意事項:

!  Username 就是你 Ubuntu 的帳號

!  把 EVB 的 USB-UART 插入電腦並執行, 看哪一個 device. 應該是 ttyUSB0

!  可以看到 chip vender

!  安裝 Putty
  • 做完以上動作應該就確認了 ttyUSB0 是否存在, 或你的 USB-UART 是另一個 device.
  • 打開 Putty 先設定好, 如下圖

  • EVB打開電源開機完,並在 Putty 裏執行 Open, Putty 的視窗應該會跑一大串文字出來, 就是系統在跑了.
  • 看看 FPGA 的 Done LED 有沒有亮, 如下圖紅框框那顆燈. 如果不亮, 你要檢查 rbf 檔有沒有在 SD Card裡面, u-boot.scr 打開來, 看檔名對不對.
