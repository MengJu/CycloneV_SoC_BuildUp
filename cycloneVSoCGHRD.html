Cyclone V SoC FPGA 參考設計流程

  • Download 以下會用到的檔案

    • Arrow SOCKIT FPGA 參考設計 下載網址

    • Toolchain 下載網址

    • Kernel 下載網址

  • 建立 SOCKIT 的 Quartus 參考設計

    • 請解壓縮你下載的 SOCKIT 的 Quatus 參考設計

    • 打開 Quartus Prime Standard → 『Open Project』, 尋找 『sockit_ghrd.qpf』 並開啟.

    • 會看到左上方有一個黃色的 Bar, 請按 『Launch IP Upgrade Tool….』

    • 會出現一視窗, 請按 『Perform Automatic Upgrade』→ close , 要等一下. 跑完了就按 close.

    • 在上方工具列找到 Tools 點一下, 會有下拉選單, 請選 『Platform Designer』, 並開啟 『sockit_ghrd.qsys 』檔案 .

    • 這次我們不修改這一個參考設計, 我們直接按 『Generate HDL』→ 『Generate』, 等一下,會跑久一點 → 『Close』→ 『Finish』.

    • 回到 Quartus, 在左上角的 Part Number 上按滑鼠右鍵 → 『Device』 → 『Devices and Pin Options...』→ 『Program Files』, 將 Raw Binary File(.rbf) 打勾, 並按 OK 退出

    • 請直接 compile 整個 Project, 跑完後, 你會在 『Project_Path/output files』這一個資料夾裡看到 sockit_ghrd.rbf 檔.
