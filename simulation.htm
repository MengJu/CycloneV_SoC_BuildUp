Use Questa to do function simulation for Intel FPGA

 

1     Envirnoment & Setup

-        Intel Quartus Prime Standard Edition 22.1 or Pro Edition 23.1

-        You need to have license for Quartus and Questa.

-        Setup the environment in Windows.

-        Setup the environment in Quartus Prime Standard.

2     Create a Quartus project

-        Open Intel Quartus Prime

-        Click New Project Wizard à Next

-        Specify the path and project name for the project à Next à Empty Project à Next.

-        Add File if you have or left it empty à Next.

-        Select the Part Number you want à Next.

-        Check the tool name of “Simulation” à Finish.

3     Create Verilog or VHDL file.

-        Add Verilog file.

 

-        Create function in the empty file as below.

-        Save the file and name it questa.v

-        Create test bench file. The steps are the same as “Add Verilog file”.

-        Save it and name it as questa_tb.v

-        Synthesis it

4      Setup the simulation environment

-        Settings

 

-        Add test bench file.

5      Start to simulation

-        Tools à Run Simulation Tool à RTL Simulation

-        Questa Simulation Tool would show up

-        Open “Wave” by click “View à Wave”

-        The Wave Window would show up without signal.

-        Add Signal name in Wave Window.

-        Run the simulation.

-        You can check if the wave is correct or not.

6      Finished
