產生 SPL & U-Boot

下載 Toolchain 並把環境設好

  • 假設, 我們在 /home也就是 ~/ 裡面放了一個名字為 cv_example.sdmmc 的資料夾, 我們將會把 sockit 的 Quartus project 放在這邊, 資料夾叫 arrow-sockit-ghrd

  • 請設定好環境以便後面有一些檔案要 copy 來 copy 去. 連來連去之類的. 同時按 Ctrl + Alt + t 打開 Terminal

$cd ~/cv_example.sdmmc


$export set TOP_FOLDER=`pwd`

  • 同時按 Ctrl + Alt + t 打開 Terminal( 如果之前的步驟你沒有把 Terminal 關掉, 請直接用哪一個未關的 Terminal)

  • 下載以及設定 Toolchain

$cd ~/


$mkdir toolchain


$wget https://developer.arm.com/-/media/Files/downloads/gnu/11.2-2022.02/binrel/gcc-arm-11.2-2022.02-x86_64-arm-none-linux-gnueabihf.tar.xz


$tar xf gcc-arm-11.2-2022.02-x86_64-arm-none-linux-gnueabihf.tar.xz


$rm gcc-arm-11.2-2022.02-x86_64-arm-none-linux-gnueabihf.tar.xz (刪除下載的壓縮檔, 這一個步驟可以不做, 把檔案移到別的地方)


$export PATH=`pwd`/gcc-arm-11.2-2022.02-x86_64-arm-none-linux-gnueabihf/bin:$PATH (讓系統知道你要用的 Toolchain 路徑, 重新開 Terminal 都要設定一次)


SPL 的產出, 會在 “arrow-sockit-ghrd” 這一個資料夾裡面產生4個檔案跟兩個資料夾

  • software/bootloader/Makefile

  • software/preloader.ds

  • software/settings.bsp

  • software/uboot.ds

  • software/bootloader/generated (這邊會有很多檔案)

  • software/bootloader/u-boot-socfpga (這邊會有很多檔案)


===============================================================================================

  • 下載 U-Boot 的 Source code.

$cd $TOP_FOLDER/arrow-sockit-ghrd


$mkdir -p software/bootloader && cd software/bootloader


$git clone https://github.com/altera-opensource/u-boot-socfpga


$cd u-boot-socfpga

  • 請做以下步驟

    • 舊的方法(要安裝 EDS, 現在不需要做了,所以Intel EDS 是不需要安裝的)


$~/intelFPGA/20.1/embedded/embedded_command_shell.sh \


bsp-create-settings \


--type spl \


--bsp-dir software/bootloader \


--preloader-settings-dir "hps_isw_handoff/soc_system_hps_0" \


--settings software/bootloader/settings.bsp

      • 新的方法(不需要 EDS)

      $cd $TOP_FOLDER/arrow-sockit-ghrd/software/bootloader/u-boot-socfpga/arch/arm/mach-socfpga/cv_bsp_generator

      $python cv_bsp_generator.py -i $TOP_FOLDER/arrow-sockit-ghrd/hps_isw_handoff/sockit_ghrd_hps_0 \

      -o ../../../../board/altera/cyclone5-socdk/qts


    • 用上面兩種方法都可以../board/altera/cyclone5-socdk/qts在產生以下檔案

      • iocsr_config.h

      • pll_config.h

      • pinmux_config.h

      • sdram_config.h



  • Build U-Boot

$cd $TOP_FOLDER/arrow-sockit-ghrd/software/bootloader/u-boot-socfpga


$export CROSS_COMPILE=arm-none-linux-gnueabihf-


$make socfpga_cyclone5_defconfig


$make -j 48

  • The following files will be built in the $TOP_FOLDER/cv_soc_devkit_ghrd/software/bootloader/u-boot-socfpga folder:

File

Description

spl/u-boot-spl

SPL ELF executable

u-boot

U-Boot ELF executable

u-boot-with-spl.sfp

Bootable file: four copies of SPL and one copy on U-Boot image
